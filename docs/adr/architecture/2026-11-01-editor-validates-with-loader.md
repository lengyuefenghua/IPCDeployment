# 编辑器复用配置加载器做保存前校验

## 背景

配置编辑器要在保存前拦住非法配置。加载器已有完整的结构与路径规则（含行列错误），编辑器如果自己再写一套校验，两套规则必然漂移，会出现「编辑器能存、程序读不了」的配置。

## 决策

- 保存前把编辑中的文档序列化到目标目录的临时文件，交给 `ConfigLoader` 校验，通过才写盘。
- 校验失败时按元素路径把临时文件的行号映射回编辑中的文档，界面据此定位节点。
- 校验通过后先写 `<文件名>.bak`，再原子替换目标文件。

## 后果

- 运行时与编辑器只有一套校验规则。
- 每次保存多一次磁盘往返；临时文件写不出会被当作校验失败。
- 保存链路依赖目标目录可写，跨目录另存时校验使用的是新目录下的 `data/`。

## 考虑过的方案

- 编辑器内实现字段级校验：两套规则漂移，放弃。
- 先覆盖目标文件再校验：失败时配置已被写坏，放弃。
