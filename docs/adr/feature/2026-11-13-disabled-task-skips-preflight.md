# 禁用任务跳过运行期预检

## 背景

任务支持 `enabled="false"`。预检包含安装包哈希、网卡/服务存在性、自启目标和顺序检查等依赖本机环境的内容，而加载器另有格式、路径前缀与源文件存在性校验。

## 决策

- 禁用任务仍参与加载期结构校验（格式、路径规则、文件存在、至少一个步骤）。
- 禁用任务跳过运行期预检，不进入执行队列，不发布任务事件、不产生步骤结果、不计入进度。
- 界面显示“已禁用”，不使用“跳过”。

## 理由

禁用的任务不会执行，其本机环境缺失不应阻断其他任务；若仍做环境预检，临时停用的选装任务（例如没有对应网卡或安装包的工位任务）会让整份配置无法开始部署。

## Considered Options

- 禁用任务仍做完整预检：环境不匹配时整份配置无法开始，与“临时停用”的用途冲突，被拒。
- 禁用任务直接从配置和报告中消失：无法解释为什么步骤没执行，也失去恢复入口，被拒。
