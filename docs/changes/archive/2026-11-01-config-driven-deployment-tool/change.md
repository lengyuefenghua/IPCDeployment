# config-driven-deployment-tool

## 需求卡

目标：把部署配置改为“分组 → 任务 → 步骤”的组合模型，让程序按任务执行，全局按任务、任务内按步骤展示执行进度，失败只结束当前任务并继续下一个任务。

验收标准：
1. 启动加载 exe 同目录的 `config.xml`；默认 `config.xml` 为 `mode="execute"`，只运行只读示例命令和等待；`config.sample.xml` 只作 preview 示例，不自动加载；`data/` 只放安装数据。
2. 左侧按 XML 顺序显示分组；右侧显示当前分组的全部任务；任务内按 XML 顺序显示安装、复制、注册表、命令、服务、网络、电源、开机自启、延时九类步骤；Command 支持 .exe/.cmd/.bat/.ps1 和内嵌 cmd/PowerShell；每页底部显示全宽日志，总览/完成为全局日志，分组页为当前任务日志。
3. 全局显示已结束任务数/总任务数；任务内显示已结束步骤数/总步骤数；失败任务计入全局进度，完成页显示失败详情。
4. 任务任一步骤失败时，结束该任务，剩余步骤显示“未执行”，自动开始下一个任务；后续分组不受影响。
5. 界面和报告不出现“跳过”；“完成”只表示执行进度，不代表成功；完成页显示每个任务的成功/失败、失败步骤、原因、未执行步骤和耗时。
6. 分组名重复、空分组、空任务、旧 schema 或未知属性被拒绝，并显示行号/列号。
7. 真实执行仍需预检、摘要和二次确认；预览模式只校验和展示，不执行。

非目标：回滚、自动重启、并行、远程部署、配置编辑器、专用 SQL 步骤、Inno Setup、自安装器。

## 协作卡（类图形）

边界：单进程 WPF 桌面程序；配置、data/ 载荷和 logs/ 都在程序目录；不使用网络服务。

共享接口：加载配置(配置文件路径) → 配置结果；开始执行(已确认、进度回调、取消令牌) → 执行报告；选择分组(分组键) → 任务集合；选择任务(任务键) → 步骤集合与任务日志；打开执行日志(日志路径) → 默认文本工具。

改动边界：新增＝分组/任务/步骤模型、左侧分组导航、右侧任务页与步骤详情、两级执行进度、任务级失败；修改＝DeploymentShell、DeploymentRunner、DeploymentReport、DeploymentViewModel、MainWindow、打包脚本；复用不动＝执行器、日志、预检、WPF-UI、net472。

不变量：preview 不创建任务进程；execute 未确认不创建任务进程；任一步骤失败只结束当前任务并继续下一个任务；全局进度按已结束任务数；分组名唯一；配置文件在 exe 同级；data/ 只放载荷。

禁止形状：视图直接启动进程；执行器实现 UI；分组独立进度环；部署整体失败状态；“跳过/skipped”状态；绕过分组/任务顺序；用原生 WPF 可见控件替代 WPF-UI。

偏离定义：新增步骤类型、改变任务级失败语义、改变配置根或分组规则、增加分组级失败门禁，必须更新本卡、delta spec 和验收。

## 流程契约

触发：应用启动、选择配置、校验配置、开始执行、选择分组、选择任务、完成导航。
入口参数：开始执行接收已确认标记、进度回调、取消令牌。

主链：
启动 → 加载 exe 同目录 config.xml → 校验与预检 → 总览（任务概况） → preview 停留 / execute 摘要与二次确认 → 左侧分组页（组内全部任务） → 选中任务（步骤子进度与任务日志） → 任务结束自动下一个任务 → 分组结束自动下一分组 → 完成页（分组/任务/步骤结果与失败详情） → 打开执行日志。

返回：成功 = 执行报告（分组、任务、步骤结果）；失败 = 配置错误、预检错误、未确认、路径不受信任、日志不可写；任务步骤失败不是整体失败，按任务记录并在完成页展示。

异常线：
- 缺少/非法 XML、旧 schema、重复组名、空组/空任务 → 总览显示行号列号，开始禁用，不执行（ERROR）。
- preview → 只校验/展示，不推进执行进度，不创建进程（INFO）。
- execute 未确认 → 不创建进程，所有任务/步骤保持未执行（WARN）。
- 步骤失败 → 当前任务失败，剩余步骤“未执行”，自动下一个任务（ERROR），不产生全局失败。
- 用户取消 → 当前步骤“已取消”，剩余步骤/任务“未执行”，不自动回滚（WARN）。
- 进程超时、回读不一致、权限不足 → 当前步骤失败，任务结束，下一个任务继续（ERROR）。
- 日志写入失败 → 回退临时目录或保留内存日志，界面提示，已运行步骤不受影响（WARN）。
- 日志导出失败 → 完成页提示错误，不影响执行结果（WARN）。

交互：任务总览页只做配置选择、任务概况和开始部署；左侧点分组切换右侧任务列表；点任务切换步骤详情；运行时自动跟随当前分组/任务；停止只取消当前运行，不自动回滚；部署完成页左侧选分组，右侧只显示该分组下的任务和步骤；每页底部全宽日志；所有可见控件保持 WPF-UI。

## 影响

- 能力：修改 deployment-operation-framework；配置模型、执行进度、失败语义、分组导航和完成页由本变更重定义。
- Data：配置文件从 data/ 移到 exe 同级；data/ 只保留载荷；schemaVersion 2.0 与旧配置不兼容；无数据库迁移。
- Risks：旧配置会被拒绝；任务级失败可能让用户误以为整机停止；自动跟随分组与手动查看可能冲突；根目录 XML 若未随包复制会导致启动失败；README 和旧 spec 仍描述旧布局/旧导航，实施时同步替换。
